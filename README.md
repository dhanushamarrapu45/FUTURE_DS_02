# 📊 Customer Retention & Churn Analysis

##  Project Overview
This project focuses on analyzing customer churn and retention using the Telco Customer Churn dataset.  
The goal is to understand why customers leave the company and identify key factors that affect customer retention.

This project is designed to simulate a real business scenario where companies want to reduce customer loss and improve long-term growth.



## Objective
- Analyze customer churn patterns
- Identify high-risk customer segments
- Understand factors influencing churn
- Provide business recommendations to improve retention

##  Key Insights
- Customers with **month-to-month contracts** have higher churn
- **New customers (low tenure)** are more likely to leave
- Customers with **higher monthly charges** tend to churn more
- Customers without **Tech Support and Online Security** show higher churn
- Customers using **electronic check** have higher churn compared to auto-payment methods



##  Recommendations
- Improve onboarding experience for new customers
- Encourage customers to switch to long-term contracts
- Review pricing for high-charge customers
- Promote support services like Tech Support and Online Security
- Encourage automatic payment methods to improve retention



## Outcome
This project demonstrates how data analysis can help businesses understand customer behavior, reduce churn, and improve customer retention strategies using Power BI.
